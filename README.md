# Interact.js 多轨道时间轴拖拽 + 吸附（生产级示例）

一个使用 Interact.js 实现的多轨道时间轴 Demo，支持片段拖拽、跨轨移动、吸附到时间刻度点、边缘缩放、碰撞检测回退、可调缩放(px/s)与吸附步长、时间标尺与播放头、选择/多选、键盘微调与删除等，适合作为生产项目的参考实现。

## 预览与运行

- 使用内置简易静态服务（推荐）：
  ```bash
  python3 -m http.server 5173 -d /workspace
  ```
  打开浏览器访问 `http://localhost:5173`。

- 或者直接双击打开 `index.html`（某些浏览器 file:// 环境下可能限制字体/跨域，建议使用本地服务）。

## 技术栈

- Interact.js（CDN 引入）实现拖拽与缩放交互
- 原生 HTML/CSS/JS，无需构建工具
- Canvas 绘制时间标尺
- CSS 变量控制轨道行高、间距与主题色

## 功能清单（Feature List）

### 时间线与轨道
- 多轨道纵向排列，支持横向/纵向滚动视图
- 行高与行间距通过 CSS 变量 `--track-height`、`--track-gap` 控制
- 网格背景按吸附步长更新纵向分割线

### 片段（Clip）
- 拖拽移动：
  - 水平时间吸附（可开关），步长可配置（支持小数）
  - 垂直吸附到轨道行，支持跨轨移动
  - 限制在时间轴范围内（非负起点）
- 边缘缩放：
  - 左/右边缘可缩放，随网格吸附
  - 最小长度不小于 1 个吸附步长
- 选中/多选：
  - 单击选中；Shift 多选/取消
  - 选中态视觉高亮
- 碰撞检测：
  - 同轨道内片段禁止重叠
  - 拖拽/缩放结束进行“快照模拟”校验，冲突则回退
- 排序与稳定性：
  - 提交后按开始时间排序，保证轨道内时序稳定
  - 拖拽/缩放过程使用 transform 降低重排

### 标尺与播放头
- 顶部 Canvas 时间标尺：
  - 自适应主/次刻度（确保可读间距）
  - 随视口滚动重绘
- 播放头（红线）：
  - 点击标尺设置位置
  - 直接拖动播放头移动
  - 支持吸附到步长

### 缩放与吸附控制
- 缩放(px/s)滑块范围 40–400
- 吸附步长(s)可直接输入，支持 0.01 精度
- 吸附开关可随时启用/禁用
- “适配内容”按钮：按当前内容时长自动计算 px/s 适配视口

### 内容操作
- “新增片段”：
  - 以播放头为起点创建新片段
  - 自动吸附；如与同轨道已有片段冲突，顺延至末尾
- “删除所选”：删除当前选中的所有片段

### 键盘快捷键
- Delete / Backspace：删除选中片段
- ← / →：按吸附步长微调选中片段起点
- Alt + ← / →：以更小的步长（步长的 1/5）微调
- Ctrl/Cmd + A：全选所有片段

### 稳定性与性能考量
- 交互事件前后重建 Interact 实例，确保缩放/步长变化后吸附与限制一致
- 使用“快照”对拟提交状态做碰撞验证，避免直接修改共享状态造成的竞态
- 像素-时间转换函数 `px()` / `sec()` 统一处理精度与显示
- 拖拽中批量移动（多选）共享偏移，减少 DOM 操作

### 可扩展性建议
- 吸附到“标记点/节拍/零交叉/波形峰值”等动态目标
- 组操作、区间选择、撤销/重做历史
- 片段锁定/静音/颜色标签、轨道折叠/静音/锁定
- 导入/导出（JSON、EDL、AAF 等）
- 虚拟化超长时间线、最小可视单位随缩放自适应

## 重要配置与数据模型

### CSS 变量（可按需调整主题/布局）
- `--track-height`：每条轨道可视高度
- `--track-gap`：轨道间距（行距）

### 关键状态（`app.js` 中的 `state`）
- `pixelsPerSecond`：像素/秒，控制时间缩放
- `snapEnabled`：是否启用吸附
- `snapIntervalSec`：吸附步长（秒）
- `tracks`：轨道数组，结构如下：
  ```js
  {
    id: string,
    name: string,
    color?: string,
    clips: Array<{
      id: string,
      name?: string,
      start: number,       // 秒
      duration: number,    // 秒
      color?: string
    }>
  }
  ```

## 代码入口与关键函数
- 渲染：`renderSidebarLabels()`、`renderRows()`、`renderClips()`
- 标尺：`drawRuler()`、`computeNiceStep()`
- 交互：`initInteract()`（拖拽/缩放、吸附、限制）
- 播放头：`setPlayheadByClientX()`、`updatePlayheadPosition()`
- 碰撞：`serializeClips()`、`hasOverlap()`、`findClip()`
- 工具：`px()` / `sec()`、`clamp()`
